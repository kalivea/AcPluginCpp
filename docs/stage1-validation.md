`AddToModelSpace` 的状态接口在 append 成功时转移数据库所有权；默认关闭实体。带 `close_entity=false` 的调用保留当前打开句柄，由调用方关闭。失败发生在 append 前时，临时实体仍由调用方拥有。旧 ID 接口消费临时实体，失败时删除尚未入库的实体。关闭后不得再访问指针。

旧 ID/bool 包装保留，部分原 void 方法改为返回 `Acad::ErrorStatus`，原有调用源码仍可忽略返回值。**部署时必须重编译依赖这些接口的模块；不保证旧二进制 DLL 的 ABI 兼容。** DWG 格式没有升级。

## 复现

在仓库根目录运行：

```powershell
# 宿主、生产源码 mock 与真实 MFC 菜单测试
./scripts/check-stage1.ps1

# 当前机器的 SDK 编译检查；临时覆盖工具集，不修改工程默认目标
./scripts/check-stage1.ps1 -SdkBuild -SdkRoot D:\Sdk\Cad2026 -Toolset v145

# 完整 AutoCAD 宿主的临时图纸回归；先完成上面的编译
./scripts/test-stage1-autocad.ps1 -FullAutoCad
```

测试输出位于忽略目录 `artifacts/stage1/`；每次 CAD 运行使用独立随机目录。`roundtrip.dwg.result.txt` 的 `POLA_STAGE1_PASS checks=68` 是运行断言结果，生成的 DWG 可供复查。测试完成后脚本清理自己启动的临时进程，不接管已有 AutoCAD 进程。

最终编译日志：`artifacts/stage1/sdk-Release.log` 和 `sdk-test-plugin.log`。最终 CAD 运行证据：`artifacts/stage1/cad-35257439e1b64eb792456c1160f08240/` 中的 DWG 与独立结果文件；该次脚本退出码为 0。SDK 库缺少调试符号的 LNK4099 警告不影响本次链接。
